# Learning together, better, faster

**On the timescales of learning social learning strategies**

Wolfram Barfuss, Paula Tittel, Richard P. Mann

*Accepted for publication in Philosophical Transactions of the Royal Society A: Mathematical, Physical and Engineering Sciences*, The Royal Society.

> Code and data repository — GitHub: [URL] | Zenodo: [DOI]

## Abstract

Social learning strategies are the foundational mechanism for human-machine cultural evolution. For decades, they have been studied either as fixed evolutionary heuristics or as rational Bayesian solutions, yet neither approach explains their remarkable flexibility nor how boundedly rational agents could acquire them. Recent work has begun to explain social learning as emerging from domain-general reward-based learning, yet, left open to address the timescales required to acquire them. Here, we investigate how quickly agents learn to rely on social information under different levels of environmental uncertainty, using boundedly rational reinforcement learning dynamics. We find that learning together not only yields better results under environmental uncertainty but can also significantly speed up learning, provided that agents have a reliable internal model of the environment. When such an internal model is not available, learning together still yields better results, but the learning speed advantage is lost. However, even model-free learning does not take significantly longer than independent learning to achieve most of the final reward that an independently learning agent achieves. Our findings suggest a concrete design principle for hybrid collective intelligence: the quality of the internal world models determines whether collaborative learning accelerates or decelerates.

## Repository structure

This repository is fully self-contained and reproducible. It contains **two separate Quarto projects** that share figures and bibliography:

| Project | Entry point | Render command | Output |
|---|---|---|---|
| Main manuscript | `Article.md` | `quarto render Article.md` | `__MS-Output/` |
| Supplementary Information | `_quarto.yml` (book project) | `quarto render .` | `__SI-Output/` |

The SI notebooks generate figures in `_figs/`, which the manuscript then uses. Cross-references between the two projects are not supported by Quarto — the manuscript references SI sections by title.

### Key files and directories

```
Article.md              — Main manuscript source (Quarto/Markdown)
ArticleAbstract.yml     — Abstract metadata
Authors.yml             — Author metadata
Bibliography.bib        — Shared bibliography
_quarto.yml             — Quarto book config for the SI
index.ipynb             — SI introduction

_code/                  — Python scripts (auto-generated from notebooks via nbdev)
_data/                  — Simulation result data (~12 MB, included)
_figs/                  — Figures (generated by SI notebooks)
__MS-Output/            — Compiled manuscript PDF
__SI-Output/            — Compiled SI PDF

j01_ENVI_*.ipynb        — SI: Environment / decision problem
j02_AGEN_*.ipynb        — SI: Agent / learning dynamics
j13–j16_RESU_*.ipynb    — SI: Results notebooks
j81_AUX_Simulation.ipynb
j82_AUX_ObtainResultsData.ipynb
j83_AUX_RobustnessChecks.ipynb
k00_References.ipynb    — SI references
```

## Reproducing the results

### Requirements

Complied with **Quarto 1.8.26** — download from [quarto.org](https://quarto.org/).

Two Quarto extensions are required and must be installed into the project directory:

```bash
# Journal template for the manuscript (arXiv format)
quarto add mikemahoney218/quarto-arxiv

# Code visibility extension for the SI PDF
quarto install extension jjallaire/code-visibility
```

**Python** — tested with Python 3.14.2 (Anaconda). The following packages are required:

| Package | Version used |
|---|---|
| numpy | 2.3.5 |
| matplotlib | 3.10.7 |
| pandas | 2.3.3 |
| scipy | 1.16.3 |
| sympy | 1.14.0 |
| scikit-optimize | 0.10.2 |
| jax | 0.8.2 |
| nbdev | 2.4.7 |

Install with conda (recommended) or pip:

```bash
# Optional but recommended: create a dedicated environment
conda create -n l2social python=3.14 && conda activate l2social

conda install numpy=2.3.5 matplotlib=3.10.7 pandas=2.3.3 scipy=1.16.3 sympy=1.14.0 jax=0.8.2
pip install scikit-optimize==0.10.2 nbdev==2.4.7
```

### Render the manuscript

```bash
quarto render Article.md
```

Output: `__MS-Output/Article.pdf`

### Render the Supplementary Information

```bash
quarto render .
```

Output: `__SI-Output/` (Quarto book PDF)

This renders the SI using the outputs already stored in the notebooks. Pre-computed data in `_data/` and stored notebook outputs mean no simulations need to be re-run by default. To force re-execution of the notebooks, pass `--execute` to the render command.

### Re-run simulations from scratch

The auxiliary notebooks `j81_AUX_Simulation.ipynb` contains simulation code (and exctracted via nbdev) that writes processed data to `_data/`. Hash-based caching means re-running with the same parameters re-uses existing files automatically; delete the relevant cache files in `_data/` to force recomputation.

## Data

The notebooks use two data directories:

- **`_data/`** (high-level) — processed results used directly by the results notebooks. Included in this repository (~12 MB). Rendering the SI and manuscript requires only this directory; no additional data download is needed.
- **Low-level simulation data** (not included) — raw simulation output written during full recomputation. The path defaults to `/Users/wolf/Downloads/L2SocialData` and is set via `lowlevel_datadictionary` at the top of the respective notebooks. If you want to rerun all simulations from scratch, update this path to a suitable local directory before executing those notebooks. Be aware that this directory can grow large (over 20 GB in the authors' setup) and that full recomputation can be time-consuming depending on the machine.
